THE SCENT OF A TEACHER — STAGE 1

FILES:
index.html — complete standalone quiz (no server or spreadsheet required)

IPHONE / GITHUB PAGES SETUP:
1. Save and unzip the downloaded ZIP in the iPhone Files app.
2. Open github.com in Safari (not just the GitHub app) and sign in.
3. Create a PUBLIC repository, e.g. scent-of-a-teacher.
4. In the repository, choose Add file > Upload files (use Safari's Request Desktop Website if needed).
5. Upload index.html itself, NOT the ZIP or enclosing folder. Commit changes.
6. Go to Settings > Pages > Build and deployment. Source: Deploy from a branch. Branch: main; folder: /(root). Save.
7. Wait for Pages to publish. Your site will normally be at https://USERNAME.github.io/scent-of-a-teacher/ (replace USERNAME with your GitHub username).
8. Open the published site and complete the quiz to test.

STAGE 1 NOTES:
- 12 teaching-belief scenarios, 4 scent-preference questions.
- Six creative teaching archetypes, secondary influence, scent pyramid, reflection.
- No responses are stored or sent anywhere.
- The fragrance notes are illustrative; not a safe-to-mix formula.
- For Stage 2, Google Sheets integration can be added later.
